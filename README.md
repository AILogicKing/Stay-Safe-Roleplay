# Stay Safe Steady Roleplay

**[Open Stay Safe Steady Roleplay](https://ailogicking.github.io/Stay-Safe-Roleplay/)**

A safety roleplay app for people who want to feel safer and more prepared.

Practice calm, practical choices for getting away, getting hidden, and getting help during threats involving armed individuals.

## Features
- **Welcome & Guidance**: Clear entry experience emphasizing preparedness and calm decision-making.
- **10,000 Safety Scenarios**: Dynamic, non-repeating scenario generator covering various locations, situations, and safe choices.
- **3D School Safety Drill**: Interactive room simulation available at any time, with 120 varied room designs and WASD/Arrow, E, and C controls.
- **3D Field Drill**: Interactive cover practice with safety feedback.
- **Safety Circle Alert Preview**: Practice creating quick location check-in messages for trusted contacts.
- **QR Code Sharing**: Scannable QR code allowing others to easily open and access the app on their devices.

## Usage
Open `index.html` in any web browser to start practicing.
